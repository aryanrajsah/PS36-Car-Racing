## Project Overview
This project is a 2D car racing game developed using Python and the Pygame library. In this game, the player steers a car left and right on a road to avoid obstacle cars coming down from the top of the screen. The player scores a point for every obstacle successfully passed. The game ends when the player's car collides with an obstacle.

## Objectives
* To understand and implement a continuous game loop running at 60 FPS.
* To learn and apply 2D graphics rendering using Pygame.
* To implement keyboard event handling for continuous player movement.
* To develop collision detection logic using Pygame Rectangles.

## Requirements
* Python 3.x
* Pygame library (`pip install pygame`)

## Execution Instructions
1. Ensure the Python file is named `one.py`.
2. Open terminal, navigate to the project directory, and run: `python one.py`

## Input/Output Details
* **Inputs:** `LEFT Arrow Key` (move left), `RIGHT Arrow Key` (move right), `R Key` (Restart).
* **Outputs:** 400x600 graphical window displaying the road, player car, obstacle cars, real-time score, and Game Over screen.
